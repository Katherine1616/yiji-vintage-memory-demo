# 衣迹 · 古着记忆流转 Demo

这是“衣迹”古着社区与私人衣橱网页 Demo 的独立代码包，包含社区浏览、衣历、试穿演示、私人衣橱、照片精选和小红书草稿等前端交互。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 目录说明

- `src/`：页面状态、静态数据和样式
- `public/assets/`：网页 Demo 使用的古着、人物和试穿素材
- `scripts/`：素材处理辅助脚本
- `vercel.json`：Vercel 部署配置

本 Demo 使用前端状态和静态素材模拟登录、衣历编辑、照片精选、试穿生成及小红书草稿，不连接真实账号、模型、交易或发布接口。
